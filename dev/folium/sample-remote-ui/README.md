# 遥控组件插槽示例

需要实现实验接口 `remote.ui` 的宿主；稳定 Folium 版本仍为 1.4。
把此目录内四个文件直接压成 ZIP，在模组管理器安装并启用，再打开独立遥控窗口。

原生播放、循环、收藏、窗口和录制按钮保持原样。底部追加区的点赞按钮、圆角计数、输入框和样式全部由此模组创建。

- 点击示例点赞，或 Tab 聚焦后按 Enter/Space：计数增加，Node 模组日志输出 `remote.ui example count`。这是离线 RPC，不发送真实点赞。
- 输入框可打字；不会触发原生播放键。
- 停用/卸载模组后追加区消失；重新启用或修改模组代码后重载，无需重开遥控窗口。
- 分别检查明/暗主题、透明控制页与录制页；附加区只在播放页出现，不覆盖原生控件。

`default` 入口在主窗口中不做事；`remoteUi(remote)` 是明确 opt-in 的实验性遥控入口，不能用来重排、隐藏或替换原生按钮。
组件的 DOM/CSS 在 ShadowRoot 内；改动外观只需修改 `client.mjs`。
